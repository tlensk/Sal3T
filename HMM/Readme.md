# DT-helix HMM search


This directory contains information about the DT-helix HMM search:

**DT-helix.hmm** - a Hidden Markov Model constructed for the Distal Tail protein core and helical extension analysis.

**MSA_DT-helix.fasta** - the seed alignment for DT-helix.hmm

**DT-helix_HMM.out** - the raw output of the DT-helix HMM search.
