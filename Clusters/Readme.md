# Clustering results

This directory contains information about the clustering results:


(1) __mmseqs2_160seqs.out__ 

MMseqs2 output file with the initial clustering of 160 DT-helix proteins (minimum sequence identity = 0.2, minimum alignment coverage = 0.2, clustering mode = "normal->slow_sensitive") annotated with the names of the clusters used in the study;

(2) __6DTcls_165seqs.txt__ 

Tab-delimited text file with the cluster assignment of 165 curated DT-helix proteins.
