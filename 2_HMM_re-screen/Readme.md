# DT-helix HMM re-screen


This directory contains information about the DT-helix HMM re-screen using a set of six HMMs. 
This HMM set was created based on the clustering of 160 DT-helix phages into six separate groups.


**.hmm** - a Hidden Markov Model (HMM) constructed for each DT-helix group.

**.fasta** - the corresponding seed Multiple Sequence Alignment (MSA) in a fasta format for each HMM.

**A_DT-h_6cls.out** - the raw output of the DT-helix HMM re-screen.
