# Tailspike analysis


This directory contains information about the conducted tailspike analysis.

__DT_165.csv__ contains pairwise percent identity for 165 DT-helix proteins.

__N-tailspike_165.csv__ contains pairwise percent identity for the extracted 165 N-term 60aa regions of tailspikes.

__C-tailspike_165.csv__ contains pairwise percent identity for the 165 remaining C-term regions of the corresponding tailspikes.

The order of genome IDs in consistent in all the three .csv files.
